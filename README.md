# WebGIS Phường Tân Thuận

WebGIS hành chính phong cách đỏ – vàng, triển khai tĩnh trên GitHub Pages.

## Nền tảng
- MapLibre GL JS
- Turf.js
- Kiến trúc lớp dữ liệu theo Vietflex WebGIS
- Vector tile PBF từ hệ thống Tân Thuận gốc
- OpenStreetMap làm nền mặc định

## Chức năng
- Ranh giới hành chính, khu phố, quy hoạch, địa chính
- Trường học, nhà trọ, cơ quan, cấp phép xây dựng
- Bật/tắt lớp
- Click tra cứu thuộc tính
- Tìm tọa độ
- GPS
- Đo khoảng cách / diện tích
- Responsive desktop/mobile

## GitHub Pages
Repository > Settings > Pages > Deploy from branch > main / root.

Trang dự kiến: https://vietflexmap.github.io/TanThuan/

> Lưu ý: các vector tile chuyên đề hiện phụ thuộc máy chủ nguồn của hệ thống Tân Thuận. Muốn 100% độc lập/offline cần xuất dữ liệu được phép sang PMTiles/GeoJSON và lưu ở hạ tầng Vietflex.
